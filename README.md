# Ghost of Yōtei numbers

Values for Ghost of Yōtei, game version 1.512: parry and dodge windows, armor, weapons, charms, skills, enemy health and damage. There is also a loadout builder that adds up your stats.

Site: https://aida64x.github.io/ghost-of-yotei-numbers/

The page is static. `app.js` renders `data.json` in the browser.
