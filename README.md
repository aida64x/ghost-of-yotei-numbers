# Ghost of Yōtei by the numbers

A reference site with the exact numbers behind Ghost of Yōtei (game version 1.512):

- parry, Perfect Parry and Perfect Dodge windows per difficulty;
- how weapon alignment works;
- detection and enemy aggression settings;
- armor, weapon, tool and charm values at every upgrade level, including New Game+;
- skills, health, Spirit and carry-capacity upgrades;
- enemy, duel and bounty-target health and block points;
- enemy damage per difficulty;
- a loadout builder that adds up every stat from your armor, charms, weapons, tools and health upgrades.

Open the site: https://aida64x.github.io/ghost-of-yotei-numbers/

It is a static page: `index.html`, `style.css` and `app.js` render `data.json` in the browser.

Ghost of Yōtei is a trademark of Sony Interactive Entertainment. This is an unofficial fan reference and contains no game assets.
